# JNLOP Web Prototype: Jubilee Nation Leadership & Operations Platform

The interactive web prototype for **JNLOP**, an operations dashboard for the Jubilee Nation church network (client project). The production build is in [jnic-management](https://github.com/dsparrowm/jnic-management).

**Live demo:** https://jubilee-nation.vercel.app

## Modules
- **People & structure:** pastors directory and profiles, staff, org structure, branches, transfers
- **Reporting:** weekly and monthly report submission, a report builder, analytics and impact
- **Operations:** approvals, tasks, calendar and events, services, leave management (apply, view own requests)
- **Finance:** finance overview and wallets
- **Comms & governance:** announcements, inbox, documents, compliance, audit log, global search

## Tech stack
React 19, TypeScript, TanStack Start/Router, Vite, Tailwind CSS, shadcn/ui (Radix), FullCalendar, deployed to Cloudflare (Wrangler).

## Getting started
```bash
pnpm install
pnpm dev
```
